Como usar
• Arraste um bloco da paleta para a área.
• Mova blocos arrastando-os.
• Puxe um fio a partir da bolinha de baixo (ou das laterais, na condição) até outro bloco.
• Clique no texto para editar.
• Use o conector (círculo) para juntar setas e criar repetições (laços).
• Selecione e aperte Delete para apagar.
